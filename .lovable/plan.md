# Radiology Imaging Centre Visual Refresh

## Goal
Refresh SavoScan.com so it feels like a premium radiology imaging centre: calm, clinical, precise and reassuring, while preserving all routes, pricing logic, lead capture and booking functionality.

## What will change
- Refine the header into a cleaner clinical navigation with a compact patient-help cue and stronger scan-price action.
- Recompose the homepage opening area around the existing radiology suite image, clearer diagnostic-imaging language, trust signals and an integrated scan search panel.
- Introduce an imaging-workstation visual language: crisp navy surfaces, cool white panels, restrained teal status accents, fine grid lines, scan labels and precise dividers.
- Restyle offer cards, scan categories, process steps, safety information and major content bands for a more credible imaging-centre presentation.
- Improve spacing, visual hierarchy and mobile behavior without changing page content, medical disclaimers or conversion flows.

## Technical details
- Update semantic design tokens and shared CSS in `src/styles.css`; no hardcoded component colors.
- Make focused markup refinements in the homepage and shared shell only.
- Reuse the existing radiology photography and current Button/navigation components.
- Preserve accessibility, reduced-motion behavior, SEO metadata, lead popup timing, WhatsApp contact and all booking links.
- Verify desktop and mobile layouts, interactions, overflow, runtime errors and build health.
